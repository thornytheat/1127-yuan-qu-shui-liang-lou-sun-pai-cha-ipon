# 分区核账与夜班复盘

按分区和夜窗取得供水总表，再扣掉池容变化和合法冲洗支出，与可用分表区间的有理数升数核对。总或分表覆盖不足时仅保留差额待查。有效供水量大于零且差额严格超过十五个百分点时标记高损耗。

阀门试验按树状消防隔离图检查。每次隔离后测得持续流量下降，给覆盖此支路的候选段增加证据。失准、迟到和未知阀不加入候选权重，独立有效次数或权重不够时保留待确认状态。

夜班隔离指令在同一套隔离图上按分区出单：截点复核有效且属于本分区的试验才可采信，迟到记录不改变本班指令，同阀点重跑不新增派工。两次独立支撑且领先份额达到六成五的支段才能定案，交阀门、听漏双资质班组隔离；未达标分区本夜只安排一次未做过的独立试验并写明待补测支段，两支接近时由系统按期望后验熵裁决先证实首选还是先排开另一支，派次与待验证支段保持同一选择。

运维人员可复核去掉一晚后压力校正基线的波动，以及应急班组退出或封区时队列里的未服务安全类工单。演练重新计算，不覆盖实际配次。
