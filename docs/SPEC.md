# 园区水量漏损排查 · 字段与计算

本项目使用确定性模拟业务数据。所有时间均以业务台账指定粒度解析。

## 记录与单位

`flow_register.json` 是按水表和时点的整数升累计计数器，版本同效冲突隔离。达到末端后的合理反跳按计数器上界换算，换表与长失联不能猜测增量。`quiet_hour_rules.json` 按分区给定半开窗口，按区间重叠分钟进行有理数分摊。时间是同一值班周内的营运分钟。

历史基线隔离计划冲洗、生产夜班与覆盖不足。按压力平方根进行流量校正。画像模型对不同营业类型用稳健缩放进行 L1 距离和 k-medoids 聚类，以设备编号稳定消歧。簇编号的评估先按混淆矩阵求一对一最大重合。

## 巡检动作

结合经验尾概率、离群距离与持续周界来判断是否出单。关阀后的持续过水可直接派给有双资质的小组。巡检容量默认 6。组间比较需考虑区间通行、班内剩余分钟与资质。复测数据只有结案后的事实，作为事后校验独立处理，不参与生成待查清单。

## 夜班隔离指令

阀门试验先过截点闸口：仅当 `reliable` 为真、`observed` 不晚于复核截点且阀点属于本分区隔离图时才采信；迟到、失准、串区、未知阀与同阀点重跑只登记复核结论，不改变本班指令，重跑不新增派工。

每个分区下一夜只出一份指令。定案须同时满足不少于两次独立支撑和领先支段份额达到 65%，定案支段交同时持有阀门与听漏资质且执勤覆盖该分区的班组。证据不足时不得定案，只安排一次此前未做过的独立试验，并在指令中列明全部待补测支段；前两名份额差不超过 0.18 视为两支接近，系统按一次试验的期望后验熵自行裁决先证实首选还是先排开另一支，派次与所选阀点保持同一选择，同分按证实首选、阀点名稳定消歧。
